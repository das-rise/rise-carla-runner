Please cite the dataset as: 

Maximilian Bäumler, Matthias Lehmann, Günther Prokop (2023). "Generating representative test scenarios: 
The "Fuse for Representativity" (FUSE4Rep) process model to collect and analyse traffic observation data". 
In: 27th ESV Conference. Yokohama. Paper NO.23-0122-O

Paper with description of data collection process is available here: https://index.mirasmart.com/27esv/PDFfiles/27ESV-000122.pdf 

############################### 
Source trajectory data was extracted from video using DataFromSky TrafficSurvey (https://ai.datafromsky.com/aerial)
- an AI video analytics-based service for gathering advanced traffic data for researchers and traffic engineers. 
We sincerely thank DataFromSky for supporting the analysis. 

The trajectories in this data set were created with (GoPro) and without (DJI Action 2) prior camera calibration. 

The raw trajectory data is stored in the .tlgx files included and can be extracted according to your research questions.
The .tlgx files can be opened with the DataFromSky Viewer, available also online: 
https://www.datafromsky.com/download/DataFromSkyViewer.exe
https://datafromsky.com/download/DataFromSkyViewer.zip

The ListDB ontology was developed by Susanne Arndt (https://orcid.org/0000-0002-1019-9151).
